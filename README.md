# codesh

사내망(폐쇄망) 환경을 위한 실시간 협업 코드 공유 서비스입니다.

외부 인터넷 연결 없이 사내망 안에서 codeshare.io의 핵심 기능을 활용할 수 있도록 설계된 시스템입니다. 광고 없이 모든 기능을 무료로 제공하며, 충돌 없는 실시간 동시 편집과 사내망 환경에 맞춘 직관적인 공유 방식을 지원합니다.

## 왜 만드는가

- 광고 및 외부 위젯 배제: 배너 광고와 외부 고객지원 스크립트를 제거하고 모든 기능을 기본 무료로 제공합니다.
- 완전한 사내망 독립 구동: 외부 CDN, 상용 웹 폰트, 분석 도구 등 런타임 외부 의존성이 전혀 없어 인터넷 차단 환경에서도 동작합니다.
- 충돌 없는 실시간 편집: CRDT(Yjs) 기반 동기화를 적용하여 동시 편집 시 내용 유실을 방지하고 일시적 연결 단절 후에도 안전하게 병합합니다.
- 링크 복사 없는 간편한 공유: 6자리 숫자 참여 코드, QR 코드, 서브넷 기반 근처 공유 목록을 통해 URL 입력 없이 빠르게 입장할 수 있습니다.
- 사내 보안 및 권한 제어: 보기 전용 링크, PIN 잠금, 대기실 승인, 강퇴 기능을 갖추며 참여자에게 삭제된 텍스트 이력을 유출하지 않습니다.

## 주요 기능

### 프로그래밍 언어별 문법 강조
- Java, Python 등 100개 이상 프로그래밍 언어 지원 (주요 언어 대상 Lezer 파서 기반 정밀 문법 적용)
- HTML 안의 JS·CSS, Markdown 코드 블록 등 섞인 언어 강조
- 다크·라이트 각 2종 이상 테마 및 배경 대비 4.5:1 이상 토큰 색상
- 프로그래밍 언어마다 고유 표시 색(점·배지)과 언어 이름을 함께 표시
- 붙여넣기 시 내용 및 파일 이름 기반 언어 자동 감지

### 기본 기능
- 첫 화면(`/`) 소개 페이지: 서비스 소개, 새 공유 생성, 6자리 참여 코드 입력, 근처 공유 목록, 데모 에디터
- 가입 없는 즉시 공유 생성 및 짧은 URL 접근
- 다중 커서와 선택 영역을 지원하는 실시간 동시 편집 및 연결 끊김 감지·자동 재연결
- 에디터 테마, 글꼴 크기, 탭 크기, 줄바꿈, 키맵(Default, Vim, Emacs, Sublime) 설정
- 언어에 맞는 확장자 자동 지정 코드 다운로드 및 복사
- 보기 전용 링크 분리, PIN 잠금, 대기실(입장 승인), 강퇴 및 차단
- UI 표시 언어는 한국어·영어 두 가지만 지원 (WCAG 2.2 AA, 전 기능 키보드 조작)

### 사내망 특화 기능
- 6자리 숫자 참여 코드로 첫 화면에서 즉시 입장
- 프로젝터용 대형 화면 모드(QR 코드 및 큰 숫자 코드)
- 동일 서브넷 및 방 그룹 내 열려 있는 근처 공유 자동 탐색
- 접속 중인 사내 사용자에게 직접 공유 초대 전송 및 방 전체 일괄 화면 띄우기
- 아바타 드래그 앤 드롭을 통한 파일·코드 조각 전달 및 대용량 업로드(폴더·zip)
- 강사가 수강생 전원의 편집 화면을 격자로 확인하고 예제를 배포하는 실습실 모드

### 고급 기능
- 다중 파일(탭/트리) 공유, 브라우저 내 코드 포매터, Markdown 미리보기, diff 보기, 줄 단위 코멘트
- 전체 편집 타임라인 재생(Playback) 및 스냅샷 복원·비교, 커서·스크롤 따라가기(Follow)
- (선택) 사내 계정(OIDC, LDAP) 연동, 감사 로그(생성, 열람, 다운로드), 비밀정보 경고

### 만들지 않는 것
- 코드 공유에만 집중하기 위해 화상·음성 통화, 화면 공유, 텍스트 채팅, 코드 실행, 면접 전용 기능, 사내 메신저 연동은 만들지 않습니다.

## 기술 구성

| 영역 | 선택 | 이유 |
|---|---|---|
| 저장소 구조 | pnpm workspaces + Turborepo 모노레포 | 웹·서버·공용 타입을 한 저장소에서 관리 |
| 언어 | TypeScript (strict) 전 구간 | 클라이언트·서버 타입 공유 |
| 웹 | React 19 + Vite, TanStack Router/Query | 빠른 개발 서버와 작은 번들 |
| 에디터 | CodeMirror 6 + `@codemirror/language-data` | Monaco보다 가볍고 모바일 지원, 언어 팩 지연 로딩, 언어별 강조 |
| 동기화 | Yjs(CRDT) + Hocuspocus 서버 | 끊긴 뒤 병합, 커서 상태(awareness) 기본 제공, 검증된 CodeMirror 바인딩 |
| 확장 | Hocuspocus Redis 확장 | 여러 서버 인스턴스 간 문서 동기화 |
| API 서버 | Fastify | 빠르고 스키마 기반 검증 |
| DB | MongoDB 8 (공식 드라이버 + zod 검증) | TTL 인덱스로 24시간 만료 자동 처리, Yjs 상태·편집 기록 저장. MySQL 8로 교체 가능 |
| 캐시/메시징 | Redis 7(Valkey 호환) | 인스턴스 간 실시간 전파, 접속자·근처 공유, 참여 코드 발급, 권한 캐시, 속도 제한 |
| 파일 저장 | MongoDB GridFS | 업로드·내보내기, 별도 저장소 서비스 없음 |
| UI | Tailwind CSS v4 + Radix UI 기반 자체 컴포넌트 | 접근성 기본기, 디자인 토큰 일관성 |
| 다국어 | 한국어·영어 메시지 파일 2개 | 지원 언어를 둘로 고정 |
| 글꼴 | Pretendard(본문), JetBrains Mono 또는 Geist Mono(코드), 자체 호스팅 | 한글 가독성, 외부 CDN 금지 |
| QR | 브라우저에서 생성(외부 API 없음) | 폐쇄망 동작 |
| 테스트 | Vitest, Playwright(다중 브라우저 동시 편집 시나리오), k6(부하) | |
| 배포 | Docker Compose(단일 서버), 오프라인 설치 번들 | |

## 개발 방식

의존성 설치(`pnpm install`), 개발 서버, 도커, 테스트, 빌드, 부하 테스트와 같은 무거운 작업(heavy commands)은 instabox 클라우드 개발 박스에서 실행하며, 로컬 머신은 코드 편집만 담당합니다. 구체적인 작업 규칙과 제약 사항은 [AGENTS.md](AGENTS.md)를 참고합니다.
