# codesh

사내망(폐쇄망) 환경을 위한 실시간 협업 코드 공유 서비스입니다.

외부 인터넷 연결 없이 사내망 안에서 codeshare.io의 핵심 기능을 그대로 활용할 수 있도록 설계된 시스템입니다. 광고 없이 모든 기능을 무료로 제공하며, 충돌 없는 동시 편집과 사내망 환경에 맞춘 직관적인 공유 방식을 지원합니다.

## 왜 만드는가

- 광고 및 외부 위젯 배제: 원본 서비스의 배너 광고와 외부 고객지원 스크립트를 제거하고 모든 기능을 기본 무료로 제공합니다.
- 완전한 사내망 독립 구동: 외부 CDN, 상용 웹 폰트, 분석 도구 등 런타임 외부 의존성이 전혀 없어 인터넷 차단 환경에서도 동작합니다.
- 충돌 없는 실시간 편집: CRDT(Yjs) 기반 동기화를 적용하여 동시 편집 시 내용 유실을 방지하고 일시적 연결 단절 후에도 안전하게 병합합니다.
- 링크 복사 없는 간편한 공유: 6자리 숫자 참여 코드, QR 코드, 서브넷 기반 근처 공유 목록을 통해 URL 입력 없이 빠르게 입장할 수 있습니다.
- 사내 보안 및 권한 제어: 보기 전용 링크, PIN 잠금, 대기실 승인, 강퇴 기능을 갖추며 참여자에게 삭제된 텍스트 이력을 유출하지 않습니다.

## 주요 기능

### 기본 기능
- 가입 없는 즉시 공유 생성 및 짧은 URL 접근
- 다중 커서와 선택 영역을 지원하는 실시간 동시 편집
- 100개 이상 언어 문법 강조 및 자동 감지
- 에디터 테마, 글꼴, 탭 크기, 키맵(Default, Vim, Emacs, Sublime) 설정
- 코드 다운로드 및 복사
- 보기 전용 링크 분리, PIN 잠금, 대기실(입장 승인), 강퇴 및 차단
- 브라우저 기반 화상·음성 통화 및 화면 공유

### 사내망 특화 기능
- 6자리 숫자 참여 코드로 첫 화면에서 즉시 입장
- 프로젝터용 대형 화면 모드(QR 코드 및 큰 숫자 코드)
- 동일 서브넷 및 방 그룹 내 열려 있는 근처 공유 자동 탐색
- 접속 중인 사내 사용자에게 직접 공유 초대 전송 및 방 전체 일괄 화면 띄우기
- 아바타 드래그 앤 드롭을 통한 파일 및 코드 조각 전달
- 강사가 수강생 전원의 편집 화면을 격자로 확인하고 예제를 배포하는 실습실 모드

### 고급 기능
- 다중 파일(탭/트리) 공유 및 브라우저 내 코드 포매터
- 전체 편집 타임라인 재생(Playback) 및 스냅샷 복원
- 사내 격리 컨테이너 환경 기반의 코드 실행 샌드박스
- 면접관 전용 메모, 타이머, 이탈 감지가 포함된 기술 면접 모드
- 사내 계정(OIDC, LDAP) 연동 및 감사 로그(생성, 열람, 다운로드)

## 기술 구성

| 영역 | 선택 |
|---|---|
| 저장소 구조 | pnpm workspaces + Turborepo 모노레포 |
| 언어 | TypeScript (strict) 전 구간 |
| 웹 | React 19 + Vite, TanStack Router/Query |
| 에디터 | CodeMirror 6 |
| 동기화 | Yjs(CRDT) + Hocuspocus 서버 |
| 확장 | Hocuspocus Redis 확장 |
| API 서버 | Fastify |
| DB | PostgreSQL 17 + Drizzle ORM |
| 캐시/메시징 | Redis(Valkey) |
| 파일 저장 | S3 호환(MinIO) |
| 화상 | LiveKit (자체 호스팅 SFU) + 내장 TURN |
| 코드 실행 | 별도 runner 서비스, 언어별 컨테이너 + gVisor/nsjail |
| UI | Tailwind CSS v4 + Radix UI 기반 자체 컴포넌트 |
| 글꼴 | Pretendard(본문), JetBrains Mono 또는 Geist Mono(코드), 자체 호스팅 |
| 테스트 | Vitest, Playwright, k6 |
| 배포 | Docker Compose(단일 서버), Helm 차트(쿠버네티스), 오프라인 번들 |

## 개발 방식

의존성 설치(`pnpm install`), 개발 서버, 도커, 테스트, 빌드, 부하 테스트와 같은 무거운 작업(heavy commands)은 instabox 클라우드 개발 박스에서 실행하며, 로컬 머신은 코드 편집만 담당합니다. 구체적인 작업 규칙과 제약 사항은 [AGENTS.md](AGENTS.md)를 참고합니다.
