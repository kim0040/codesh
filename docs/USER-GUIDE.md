# 사용자 안내서 (User Guide)

codesh는 사내망 환경에서 동작하는 실시간 협업 코드 공유 도구입니다. 외부 인터넷 연결이나 계정 가입 없이 브라우저에서 바로 코드를 공유하고 함께 편집할 수 있습니다.

---

## 1. 시작하기와 입장하기

### 1.1 새 공유 만들기
- 첫 화면(`/`)에서 **새 공유 만들기** 버튼을 누르면 새로운 코드 공유 세션이 생성됩니다.
- 생성 즉시 고유한 8자리 영숫자 주소(`/<id>`)와 6자리 숫자로 된 **참여 코드**가 발급됩니다.
- 공유를 만든 사용자는 해당 공유의 **소유자**가 됩니다.

### 1.2 6자리 참여 코드로 입장
- 첫 화면의 입력란에 전달받은 6자리 숫자를 입력하고 **입장** 버튼을 누르거나 Enter 키를 누릅니다.
- 브라우저 주소창에 `/<6자리코드>`를 직접 입력해도 해당 공유로 바로 이동합니다.
- 참여 코드는 공유가 살아 있는 동안 유지됩니다. 저장하지 않은 공유는 만료될 때 코드도 함께 사라지고, 내 공유에 저장한 공유의 코드는 계속 유지됩니다. 사라진 코드는 다른 공유와 헷갈리지 않도록 24시간 동안 다시 발급되지 않습니다.

### 1.3 QR 코드 및 전체 화면 보기
- 상단 바의 **공유** 버튼(단축키 `⌘⌥S` 또는 `Ctrl+Alt+S`)을 누르면 **코드·QR** 탭에 참여 코드와 QR 코드가 표시됩니다.
- 휴대폰 카메라로 QR 코드를 비추면 모바일 브라우저로 바로 입장할 수 있습니다(단, 휴대폰이 사내 동일 네트워크나 Wi-Fi에 연결되어 있어야 합니다).
- 회의실이나 강의실에서는 **전체 화면으로 보기**를 눌러 큰 글씨의 6자리 코드와 대형 QR 코드를 프로젝터 화면에 띄울 수 있습니다. `Esc` 키나 닫기 버튼으로 종료합니다.

### 1.4 근처 공유
- 첫 화면의 **근처 공유** 목록에는 현재 같은 네트워크 그룹(사내 방 단위 또는 서브넷)에서 열려 있는 공유가 실시간으로 나타납니다.
- 목록에는 공유 제목, 언어, 현재 참여 중인 인원수, 최근 활동 시간, 그리고 본문 첫 8줄의 미리보기가 표시됩니다.
- 원하는 항목의 **입장** 버튼을 누르면 즉시 참여할 수 있습니다.
- PIN 잠금이나 입장 승인이 설정된 공유는 근처 공유 목록에 노출되지 않습니다.

### 1.5 사람에게 보내기
- 공유 창의 **보내기** 탭에서 **사람에게 보내기**를 선택합니다.
- 현재 같은 네트워크에 접속 중인 사용자 목록이 표시되며, 이름 검색이 가능합니다.
- 필요한 경우 최대 200자의 **메모**를 입력하고 해당 사용자 옆의 **보내기** 버튼을 누릅니다.
- 수신자의 화면에 발신자 이름, 공유 제목, 언어, 메모가 포함된 알림이 표시되며, **공유 열기** 버튼을 눌러 입장할 수 있습니다.

### 1.6 방 전체에 띄우기
- 공유 창의 **보내기** 탭 하단에서 **방 전체에 띄우기** 영역을 확인합니다.
- 네트워크 관리자가 방(room)을 설정한 경우 해당 방의 모든 접속자에게, 그렇지 않은 경우 동일 서브넷의 모든 접속자에게 일괄 초대를 보냅니다.
- **모두에게 띄우기**를 누르고 확인 대화상자에서 승인하면, 접속 중인 모든 사람의 화면에 알림이 표시되어 버튼 한 번으로 입장할 수 있습니다.

## 2. 함께 편집하기

### 2.1 다중 커서와 참여자 상태
- 여러 사람이 동시에 같은 문서를 편집해도 충돌 없이 내용이 실시간 병합됩니다(Yjs CRDT 기반).
- 각 참여자의 커서 위치와 선택 영역이 고유한 색상 및 이름 태그와 함께 실시간으로 표시됩니다.
- 상단 바의 참여자 아바타를 누르면 해당 사용자의 커서와 스크롤 위치를 실시간으로 추적하는 **따라가기** 기능이 동작합니다.

### 2.2 여러 파일 및 폴더 관리
- 한 공유에는 최대 100개까지 파일을 포함할 수 있습니다.
- 상단 파일 탭 스트립 또는 좌측 파일 패널에서 **새 파일**을 추가하거나 기존 파일의 이름을 변경하고 삭제할 수 있습니다.
- 파일 이름에 슬래시(`/`)를 입력하여 폴더 구조를 만들 수 있습니다(예: `src/index.ts`).
- 파일 이름의 확장자에 따라 프로그래밍 언어가 자동으로 감지됩니다.

### 2.3 언어와 문법 강조
- JavaScript, TypeScript, Python, Java, C++, Go, Rust, SQL, Markdown 등 100개 이상의 프로그래밍 언어 문법 강조를 지원합니다.
- 하단 상태 표시줄의 언어 영역을 클릭하여 언어를 직접 검색하고 변경할 수 있습니다. 언어를 변경하면 공유의 모든 참여자에게 동일하게 적용됩니다.
- 에디터 내 모든 문법 토큰 색상은 WCAG 2.2 AA 기준(배경 대비 4.5:1 이상)을 충족합니다.

### 2.4 줄 단위 코멘트
- 코드의 특정 줄 또는 범위를 선택한 후 단축키 `⌘⌥M` (Windows: `Ctrl+Alt+M`)을 누르거나 상단 바의 **코멘트** 버튼을 누릅니다.
- 코멘트 작성 창에서 내용을 입력하고 **등록**을 누릅니다(최대 2,000자).
- 코멘트는 문서 내부의 상대 위치로 고정되므로, 다른 사용자가 문서 앞부분에 코드를 추가하거나 삭제해도 본래 위치를 유지합니다.
- 해결된 대화는 **해결됨으로 표시** 버튼으로 정리할 수 있으며, 필요 시 **다시 열기**가 가능합니다. 패널 상단의 스위치로 해결된 코멘트를 숨기거나 볼 수 있습니다.

### 2.5 이력 재생과 버전 복원
- 공유의 **소유자**만 상단 바의 **이력** 버튼(단축키 `⌘⌥H` 또는 `Ctrl+Alt+H`)을 열 수 있습니다.
- 편집 활동 중 약 30초 간격으로 스냅샷이 자동 생성되며 최대 100개 버전까지 타임라인에 기록됩니다(기본 7일 보관).
- **재생** 버튼을 누르면 코드가 작성되어 온 과정을 1배속, 2배속, 4배속으로 재생할 수 있습니다.
- **현재와 비교**를 선택하면 특정 시점과 현재 문서 사이의 차이점(diff)을 한 화면에 겹쳐 보여 줍니다.
- **버전 복원**을 누르면 문서 전체가 해당 시점의 상태로 되돌아갑니다. 복원은 기존 이력을 지우지 않고 일반 변경 사항으로 추가되므로 안전합니다.

### 2.6 지운 내용 보호
- 다른 일반 참여자에게는 항상 현재 시점의 문서 최종 내용만 전송됩니다.
- 과거에 입력했다가 삭제한 텍스트 이력은 일반 참여자의 브라우저로 전송되지 않으며, 서버에만 보관되어 소유자만 이력 창에서 확인할 수 있습니다.

### 2.7 다운로드와 ZIP 내보내기
- 단일 파일 다운로드: 상단 바 메뉴에서 **다운로드**를 선택하거나 파일 옵션 메뉴에서 **이 파일 다운로드**를 누르면 해당 언어에 맞는 확장자로 즉시 다운로드됩니다.
- 전체 다운로드: 공유에 여러 파일이 포함된 경우 **전체 .zip 다운로드**를 선택하여 전체 폴더 구조를 압축 파일로 내려받을 수 있습니다.

### 2.8 업로드 및 드래그 앤 드롭
- 파일, 폴더, 또는 `.zip` 파일을 브라우저 창으로 끌어다 놓으면 공유에 파일이 추가됩니다.
- 여러 파일 공유를 새로 열거나, 공유 대화상자의 접속자 목록에서 특정 사용자의 아바타 위로 파일을 끌어다 놓으면 해당 사용자에게 파일을 바로 전송할 수 있습니다.
- 단일 요청당 최대 업로드 용량은 관리자 설정(`maxUploadMB`, 기본 200MB)에 따르며, 코드 텍스트 용량은 문서 한도(`maxDocBytes`, 기본 5MB)를 초과할 수 없습니다.

## 3. 권한 및 접근 제어

공유 대화상자의 **접근 설정** 탭에서 소유자는 다음과 같은 보안 기능을 설정할 수 있습니다.

### 3.1 보기 전용 링크와 편집 링크
- 기본 권한을 **보기 전용**으로 설정하면 링크나 코드로 들어온 사람은 문서를 읽을 수만 있고 편집할 수 없습니다.
- 소유자는 **편집 링크**(`?k=<editKey>`)를 별도로 복사하여 신뢰할 수 있는 특정 참여자에게만 편집 권한을 부여할 수 있습니다.

### 3.2 PIN 잠금
- 4자에서 32자 사이의 숫자 또는 문자로 PIN을 지정할 수 있습니다.
- PIN이 설정된 공유에 접근하는 사용자는 비밀번호 입력 화면을 거쳐야만 내용에 접근할 수 있습니다.
- 연속으로 5회 잘못 입력하면 무차별 대입 공격 방지를 위해 해당 사용자 및 IP 주소에 대해 10분 동안 입장이 차단됩니다.
- PIN이 설정된 공유는 근처 공유 목록에 표시되지 않습니다.

### 3.3 대기실 (입장 승인)
- **입장 전에 내가 승인** 옵션을 켜면, 새로 접속을 시도하는 사용자는 "승인을 기다리는 중" 화면에 머무르게 됩니다.
- 소유자 화면에 입장 요청 알림이 뜨며, 소유자가 **입장 승인**을 눌러야만 입장이 완료됩니다. 거절되면 그 요청으로는 입장할 수 없고, 다시 요청하면 소유자에게 새 알림이 갑니다.
- 대기실이 설정된 공유 역시 근처 공유 목록에서 숨겨집니다.

### 3.4 내보내기 및 차단
- 공유 대화상자의 **참여 중인 사람** 목록에서 특정 참여자 옆의 아이콘을 눌러 제어할 수 있습니다.
- **내보내기**: 해당 사용자의 접속을 끊습니다. 사용자는 코드나 링크로 다시 입장할 수 있습니다.
- **내보내고 차단**: 해당 사용자를 즉시 추방하고 차단 목록에 등록합니다. 차단된 사용자는 해당 공유에 다시 입장할 수 없습니다.

### 3.5 편집 잠금
- **편집 잠금**을 켜면 소유자를 제외한 모든 참여자의 에디터가 읽기 전용 상태로 전환됩니다.
- 강사나 발표자가 설명을 진행하는 동안 참여자들의 수정을 일시적으로 멈추고자 할 때 사용합니다.

## 4. 강사용 실습실 모드

교육 환경을 위한 실습실 모드(`/lab/new`, `/lab/:id`)를 제공합니다.

### 4.1 실습실 생성과 입장
- 주소창에 `/lab/new`를 입력하여 새 실습실을 생성하면 6자리 실습실 코드가 발급됩니다.
- 수강생은 첫 화면에서 실습실 코드를 입력하고 본인의 이름을 등록하여 입장합니다.
- 입장 시 각 수강생마다 독립적인 개인 공유 복사본이 자동으로 생성됩니다.

### 4.2 수강생 화면 실시간 격자 확인
- 강사 화면에서는 모든 수강생의 코드 작성 상태를 실시간 격자(Grid)로 한눈에 볼 수 있습니다.
- 각 수강생 카드에는 최근 수정 시간, 접속 상태(온라인/오프라인), 코드 미리보기가 표시됩니다.
- 수강생 카드의 **크게 보기**를 눌러 확대해 보거나, **들어가서 고치기**를 눌러 해당 수강생의 에디터에 직접 참여해 코드를 지도할 수 있습니다.

### 4.3 전원에게 예제 보내기
- 강사가 본인의 공유 중 하나를 예제로 선택하여 **전원에게 배포**를 누를 수 있습니다.
- 배포가 진행되면 모든 수강생의 작업 공간에 해당 예제 코드가 각각 복사본 형태로 전달됩니다.

### 4.4 실습실 전체 편집 잠금
- 강사가 상단 헤더의 **편집 잠금** 버튼을 누르면 모든 수강생의 에디터가 일괄적으로 읽기 전용으로 잠깁니다.
- 설명이 끝난 뒤 **편집 잠금 해제**를 누르면 다시 수강생들이 자유롭게 코드를 수정할 수 있습니다.

## 5. 설정과 단축키

상단 바의 메뉴에서 **설정**(단축키 `⌘,` 또는 `Ctrl+,`)을 열 수 있습니다. 모든 설정은 브라우저 로컬 저장소에 기기별로 즉시 저장됩니다.

### 5.1 화면 설정
- **앱 테마**: 시스템 설정 따라가기, 라이트, 다크
- **화면 언어**: 한국어, English
- **에디터 테마**:
  - 다크 계열: Slate, Graphite
  - 라이트 계열: Paper, Sand
- **글꼴 크기**: 12px ~ 24px (기본값 14px)

### 5.2 편집 설정
- **탭 크기**: 공백 2칸, 4칸, 8칸
- **들여쓰기 방식**: 공백, 탭
- **긴 줄 바꿈**: 켜기 / 끄기
- **줄 번호 표시**: 켜기 / 끄기

### 5.3 키맵 설정
- 선호하는 에디터 조작 방식에 따라 키맵을 변경할 수 있습니다.
  - **기본** (Default)
  - **Vim**
  - **Emacs**
  - **Sublime**

### 5.4 단축키 목록

| 동작 | macOS | Windows / Linux |
|---|---|---|
| 명령 팔레트 열기 | `⌘ K` | `Ctrl + K` |
| 단축키 안내 보기 | `?` | `?` |
| 공유 창 열기 | `⌘ ⌥ S` | `Ctrl + Alt + S` |
| 에디터 설정 열기 | `⌘ ,` | `Ctrl + ,` |

## 6. 자주 묻는 질문 (FAQ)

**Q. 공유는 얼마나 오래 유지되나요?**  
저장하지 않은 공유는 마지막 활동으로부터 24시간(관리자 설정)이 지나면 자동 만료되어 삭제됩니다. 상단 바의 **내 공유에 저장**을 눌러 보관한 공유는 만료되지 않고 계속 유지됩니다.

**Q. 내가 작성한 코드는 사내에서 누가 볼 수 있나요?**  
공유 링크나 6자리 코드를 가진 사람은 누구나 열람할 수 있습니다. 접근을 제한하려면 PIN 잠금이나 입장 승인(대기실) 기능을 사용하세요. 과거 편집 이력은 소유자만 볼 수 있으며 지운 내용은 다른 참여자에게 전송되지 않습니다.

**Q. 사내망 밖에서도 접속할 수 있나요?**  
아닙니다. 외부 인터넷과의 연결 없이 사내 폐쇄망 안에서만 동작하도록 설계되어 있습니다.

**Q. 모바일 기기에서도 동일하게 사용할 수 있나요?**  
네, 모바일 브라우저에 최적화된 인터페이스를 제공합니다. 화면이 작은 기기에서는 화면 너비에 맞춰 탭 스트립과 패널이 유연하게 축소됩니다.

## 7. 문제 해결 (Troubleshooting)

### 7.1 다시 연결하는 중... (Reconnecting)
- 일시적으로 네트워크 연결이 끊기면 화면 상단에 "오프라인이에요 – 변경 내용은 이 기기에 보관되고, 다시 연결되면 합쳐져요" 알림이 나타납니다.
- 브라우저의 로컬 저장소(IndexedDB)에 입력 내용이 안전하게 유지되므로 안심하고 계속 입력하셔도 됩니다.
- 연결이 복구되면 자동으로 서버와 병합되며 "다시 연결됐어요. 변경 내용을 합쳤어요" 안내가 표시됩니다.

### 7.2 PIN 입력 오류 및 차단 (PIN Refused)
- 올바르지 않은 PIN을 5회 연속 입력하면 무차별 대입 방지 정책에 의해 10분간 잠금 상태가 됩니다.
- 10분이 지난 후 공유 소유자에게 올바른 PIN을 다시 확인하여 입력하세요.

### 7.3 만료된 공유 또는 없는 공유
- 6자리 참여 코드가 만료되었거나 공유가 삭제된 경우 "없는 공유예요" 또는 "만료된 공유예요" 화면이 나타납니다.
- 소유자에게 새 초대 링크를 요청하거나 새로운 공유를 생성하세요.

## 8. English Quick Reference

### Starting and Joining
- **Create**: Click **Create a share** on the home page (`/`) to start an instant sharing session. No account required.
- **Join with Code**: Enter the 6-digit code on the home page or open `/<6-digit-code>` in your browser.
- **QR Code & Projector**: Use the **Share** dialog (`⌘⌥S` / `Ctrl+Alt+S`) to view the join code and QR code. Use **Projector mode** for large classroom display.
- **Nearby Shares**: Shares open on your local network/room appear automatically on the home page.
- **Send to Person & Broadcast**: Send direct invitations with an optional note (up to 200 chars) or broadcast to the entire room.

### Collaboration & Editing
- **Real-Time Sync**: Conflict-free concurrent typing powered by Yjs CRDT with remote cursors and selection highlights.
- **Multiple Files**: Support for up to 100 files and folder paths. Automatic language detection by file extension.
- **Comments**: Anchor comments to lines or selections (`⌘⌥M` / `Ctrl+Alt+M`). Comments track document edits using relative positions.
- **History & Restore**: Owners can inspect timeline snapshots, play back edits at 1x/2x/4x, compare a version with the current text, and restore it.
- **Download**: Download single files with matching extensions or export all files as a `.zip` archive.
- **Drag & Drop**: Drop files, folders, or `.zip` archives directly into the editor.

### Access Control
- **View-Only Mode**: Default to read-only access. Share the separate edit link with collaborators who need edit rights.
- **PIN Lock**: Secure the share with a 4–32 character PIN (scrypt hashed). 5 invalid attempts trigger a 10-minute lockout.
- **Waiting Room**: Require owner approval for every newcomer before granting access.
- **Lock / Kick / Ban**: Owners can lock edits across all participants, temporarily kick users, or permanently ban them.

### Settings & Keymaps
- **Appearance**: Dark and Light app themes; editor themes (Slate, Graphite, Paper, Sand); font size (12–24px).
- **Keymaps**: Default, Vim, Emacs, and Sublime.
- **Language**: Switch UI between Korean (default) and English.
